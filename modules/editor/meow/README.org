#+TITLE: Meow - Modal editing

[[https://github.com/meow-edit/meow][Meow]] is a modal editing mode designed to integrate cleanly with Emacs
conventions. Unlike [[https://github.com/emacs-evil/evil][Evil]], it avoids shadowing built-in keybindings.

* Key design decisions
- [[https://github.com/meow-edit/meow/blob/master/KEYBINDING_QWERTY.org][QWERTY layout]]

* Keybindings
** Motion mode
| Key        | Action    |
|------------+-----------|
| =j=        | meow-next |
| =k=        | meow-prev |
| =<escape>= | ignore    |

** Leader (SPC)
| Key   | Action                   |
|-------+--------------------------|
| =0-9= | meow-digit-argument      |
| =/=   | meow-keypad-describe-key |
| =?=   | meow-cheatsheet          |
